# Work tracking

GitHub is the source of truth for plans, decisions, task status, and completion checks. Do not maintain a second backlog in Markdown.

- [Milestones](https://github.com/hueypov/lexema/milestones): goals and progress.
- [Issues](https://github.com/hueypov/lexema/issues): tasks, decisions, evidence, and completion checks.
- [Pull requests](https://github.com/hueypov/lexema/pulls): implementation, review, and linked issue closure.

The current goal is a working Italian search website before complete dictionary cleanup. Older API-first plans and existing code are not accepted as correct without fresh review. See the milestone descriptions for scope; do not infer approval to publish.

[Dataset checks](DATASET_SPOT_CHECK.md) and [source research](SOURCE_RESEARCH.md) retain supporting evidence, not a parallel task list.
