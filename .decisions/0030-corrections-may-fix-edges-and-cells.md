# 0030 — A curated correction may also add or fix a form_of edge and set a conjugation cell, never edit the record

**What this decides:** Besides gender and number, Lexema may correct two more kinds of source fact beside the record: a form's `form_of` edge (adding a missing one, or fixing one that names the wrong word), and one cell of a verb's conjugation table. Each still needs evidence and a ruling, and the imported record stays byte for byte. This amends [ADR 0027](0027-curated-corrections-are-cited-exceptions.md) in part.

## Context

[ADR 0027](0027-curated-corrections-are-cited-exceptions.md) allows a curated correction to set a record's gender or number (`CorrectableValues` in `src/italian/curatedCorrections.ts`). Its Consequences say a new dimension extends the layer under its rules, but the census of every word page ([#707](https://github.com/povlabs/lexema/issues/707)) found source facts of other kinds that the page cannot set right without guessing:

- **A form record with no `form_of` edge.** `aerei`'s noun record says "plurale di aereo", and `costruttori`'s says "plurale di costruttore", but neither carries an edge, so the page reads each as a word of its own ([#715](https://github.com/povlabs/lexema/issues/715) measured 753 pages with such a record). The manifest's "no edge is invented" and [ADR 0019](0019-source-text-may-be-normalized.md)'s rule that a normalization adds no fact both forbid the page from adding the edge itself.
- **An edge that names the wrong word.** `parti`'s senses 2 and 3 are about `parto`, whose table lists `parti`, but their edges name `neonato` and `Parti` ([#701](https://github.com/povlabs/lexema/issues/701)).
- **A wrong conjugation cell.** `assorbire`'s plural essere cells read `siamo assorbito, assorti, assorti` as the source stores them ([#685](https://github.com/povlabs/lexema/issues/685); assorbire's line in `fixtures/essere-compound-cells.jsonl`).

On 2026-10-07 Huey answered every question on [#708](https://github.com/povlabs/lexema/issues/708) "all yes" ([ruling](https://github.com/povlabs/lexema/issues/708#issuecomment-6047197445)), each question's recommended answer being the ruling. Questions 7 to 10 ([asked here](https://github.com/povlabs/lexema/issues/708#issuecomment-6037557199)) approve these three corrections. This record transcribes that ruling. It is a new ruling, not a refinement of ADR 0027's own mechanics, so it amends ADR 0027 in part; ADR 0027's other decisions stand.

## Decision

**A curated correction may add a missing `form_of` edge, replace an edge that names the wrong word, or set one cell of a verb's conjugation table, each beside the record on cited evidence and a ruling, and never by editing the record.**

- **A `form_of` edge added by a ruled rule (Q7, Q8).** A ruled rule adds a `form_of` edge to a word X on a form record that has no edge, only when both hold: the record's gloss names X after "di", and X's own forms table lists the record's word. `aerei` and `costruttori` then read as forms of `aereo` and `costruttore`. Every record the rule does not confirm stays as the source states it. The rule is named and versioned like `it-plural-gloss-number` (ADR 0027's first amendment), reads only the record's archive line and the evidence it cites, and changing what it confirms is a new version and a new ruling.
- **A wrong edge fixed on the same evidence (Q9).** The same kind may replace an edge that names the wrong word, under the same two conditions: the gloss names X after "di", and X's table lists the word. `parti`'s senses 2 and 3 then point to `parto`.
- **A conjugation cell set by hand (Q10).** A hand correction sets one cell of a verb's conjugation table, citing the pinned Wiktionary conjugation page by revision id. The first are `assorbire`'s plural essere cells.
- **The same layer, the same rules.** These are new dimensions of ADR 0027's layer, not a new exception to the read-only rule. Where and how each kind is stored is the building issue's work.

**Binding constraints.**

- Every binding constraint of [ADR 0027](0027-curated-corrections-are-cited-exceptions.md) holds for these kinds: `source_record_json` and the record's imported rows stay byte for byte; no correction without a cited source revision and a ruling; no mark of a correction on the page ([ADR 0016](0016-page-shows-no-origin-marks.md)); no correction carried onto a record that replaces the corrected one.
- The page never guesses an edge. An edge exists on the page only where the source states it or a correction of this kind adds or fixes it.
- An edge correction requires both the gloss naming X after "di" and X's own forms table listing the word. A gloss alone, or a table alone, is not evidence.
- A cell correction sets one cell, and cites the pinned conjugation page that shows it. Its spelling is the page's, never one Lexema writes ([ADR 0012](0012-archive-is-the-release-seed.md)'s "No text authored by Lexema is written by the seed" stands). The 2026-10-08 [amendment on a cell's spelling](#amendments) narrows this where the page itself carries the source's error.
- [ADR 0023](0023-foreign-records-are-hidden-not-deleted.md) still holds: a hidden record has no `form_of_edge` rows, and no edge correction gives it one.
- These corrections reach the shared dictionary only through a change declaration and the dictionary deploy. No agent writes D1.

## Consequences

- [#709](https://github.com/povlabs/lexema/issues/709)'s tests and the fixes after them have a written rule for `aerei`, `costruttori`, `parti` and `assorbire`.
- How many records the edge rule corrects is not measured; the fix issue measures it ([#715](https://github.com/povlabs/lexema/issues/715) counted 753 pages with a form record and no edge).
- 745 senses on `it-0c432803` have a wrong edge that a correction replaces: `parti`'s two by hand, and 743 by rule `it-form-of-gloss-edge/v2`, 665 of them naming the reflexive form of the gloss's verb and 78 another word ([#733](https://github.com/povlabs/lexema/issues/733), [report](../reports/2026-10-09-form-of-gloss-edges-v2.md)). Only `assorbire` is known to have a wrong cell. Other verbs with two participles are not measured, and each further cell needs its own ruling.
- 600 meaning senses on `it-0c432803` carry an edge to a word their gloss merely mentions, which a correction removes (342) or points at the record's own base word (258), under the 2026-10-09 [amendment](#amendments) ([#755](https://github.com/povlabs/lexema/issues/755)).
- A feed update that replaces a corrected record reports the correction and drops it, as for gender and number; whether to correct the new record is a new ruling.

## Amendments

- **An edge correction cites the two Wiktionary pages it comes from (2026-10-08).** The building issue first had each edge correction cite two lines of Lexema's archive: the record's own gloss and the base word's forms cell. Huey ruled against it ([ruling](https://github.com/povlabs/lexema/issues/722#issuecomment-6058471600), verbatim: "no who cares about our data, we got that from wikti, cite wikti that's all"). So an edge correction cites two it.wiktionary pages, each pinned by revision id: the record's own page, which shows the gloss naming X after "di", and X's page, whose forms table lists the word. The revision is the one in the dump the archive was extracted from (`itwiktionary-20260701` for `it-0c432803`), so each link shows the text the archive read. The rule reads that dump only for those revision ids, and a sense whose page or X's page has no revision there gets no edge. The two conditions above are unchanged: the gloss and the table are still the evidence, and the pages are where they are cited.
- **A cell's spelling may be the regular one when the cited page carries the error itself (2026-10-08).** Building [#723](https://github.com/povlabs/lexema/issues/723) found that the pinned it.wiktionary conjugation page of `assorbire` ([revision 2506943](https://it.wiktionary.org/w/index.php?title=Appendice:Coniugazioni/Italiano/assorbire&oldid=2506943)) renders the same `siamo assorbito, assorti, assorti` the source stores, because its template does; en.wiktionary shows no essere cell for the verb. No page shows a right cell, so the binding constraint "Its spelling is the page's" could not be met. It also found 21 wrong plural essere cells, not 12: condizionale passato, congiuntivo passato and congiuntivo trapassato carry the same text ([evidence](https://github.com/povlabs/lexema/issues/723#issuecomment-6051228306)). Huey was asked both questions ([asked here](https://github.com/povlabs/lexema/issues/723#issuecomment-6051235020)) and answered "yes" to each ([ruling](https://github.com/povlabs/lexema/issues/723#issuecomment-6058488913)): the fix uses the regular essere spelling (`siamo assorbiti/e`) though no page shows it, in all 21 cells, and it cites the Wiktionary page the cells came from, noting that the page carries the error, as he ruled on [#722](https://github.com/povlabs/lexema/issues/722) ("we got that from wikti, cite wikti that's all").
  - **What changes.** Where the pinned page the source read a cell from carries the same error, a cell correction may spell the cell in the regular pattern the rest of the verb's table follows, on a ruling naming the cells. It still cites that page by revision id, and its evidence says the page shows the error. `assorbire`'s plural essere cells read `<auxiliary> assorbiti, assorti`, as every other plural essere cell agrees, and `it-essere-agreement/v1` shows their feminine like any other.
  - **How it is stored.** One list entry may set several cells of one record, each named by its place in `forms[]` and the text the line holds there, and each stored as its own `corrected_form` row beside the record (`CellCorrection` in `src/italian/curatedCorrections.ts`). `source_record_json` and the record's `lookup_form` rows stay as imported, and a lookup reads each corrected cell in place of the source's spelling.
  - **What it amends.** This narrows this record's "Its spelling is the page's, never one Lexema writes" for such cells only. It also amends [ADR 0012](0012-archive-is-the-release-seed.md) in part, as [ADR 0008](0008-generated-explanations-are-labelled-and-reportable.md)'s 2026-10-03 amendment did for an approved definition: the seed may write such a ruled cell spelling into `corrected_form`, beside the record it corrects, and no other Lexema text. A cell whose right spelling no ruling names stays as the source states it, and every other binding constraint above holds.
- **A ruled rule may replace every edge that names another word (2026-10-08).** Q9 fixed only `parti`'s two edges, by hand. Building [#722](https://github.com/povlabs/lexema/issues/722) found 746 more senses whose form gloss names X after "di", whose X's table lists the word, and whose edge names another word: `porta`'s "... di portare" names `presente`, and many name the reflexive form of the gloss's verb (`svestito`, "participio passato di svestire, svestirsi", names `svestirsi`) ([#733](https://github.com/povlabs/lexema/issues/733)). Huey was asked whether to fix only the edges that are neither X nor its reflexive form, and ruled to fix all of them ([ruling](https://github.com/povlabs/lexema/issues/733#issuecomment-6066281058), verbatim: "hm we should build all i think that's better").
  - **What changes.** Q9 reaches beyond `parti`: a ruled rule may replace any edge that names another word, under the same two conditions, reflexive-verb edges included. Rule `it-form-of-gloss-edge/v2` does it, and makes every correction v1 makes, identically. It also holds v1's other conditions: the record is Italian, the gloss does not name the record's own word, both pages have a revision in the dump, and no hand entry sets the sense.
  - **How it is stored.** Each replacing correction keeps the source's edge verbatim beside it (`CorrectedEdge.replaces`), as `parti`'s hand entries do, and cites the record's page and X's by revision id, as the first amendment above requires. It is written as a `corrected_edge` row like any other; `source_record_json` and the record's `form_of_edge` rows stay as imported.
  - **The count.** On `it-0c432803` v2 replaces 743 edges: 665 name the reflexive form of the gloss's verb, and 78 another word. The other 3 of the 746 are records of another language, which stay as the source states them ([report](../reports/2026-10-09-form-of-gloss-edges-v2.md)).
- **A meaning sense's edge may be removed, or pointed at its record's own base word (2026-10-09).** The extractor tags every sense of a form record as a form, so a sense whose gloss states a meaning still carries an edge to a word the gloss merely mentions: `mele`'s senses 1 to 3, "guance, soprattutto nei bambini:", "natiche o mammelle tondeggianti, ..." and "percosse", name `bambini`, `tondeggianti` and `percosse`, and `scandinava`'s "relativa alla Scandinavia" names `Scandinavia` ([#755](https://github.com/povlabs/lexema/issues/755)). Neither condition of this record holds for them, since the gloss names no form, so no correction above could touch them. Huey was asked whether a ruled correction should drop such an edge and, where the record also has a real form sense, point it at the record's own base word instead ([asked here](https://github.com/povlabs/lexema/issues/755#issuecomment-6072012737)), and answered "yes" to both ([ruling](https://github.com/povlabs/lexema/issues/755#issuecomment-6076090404)). He asked for this amendment, not a new record.
  - **What changes.** A ruled rule may remove the edge of a meaning sense: a sense of an Italian record that declares an edge, whose gloss has no form opening and no word that names a form. Where the record has a real form sense naming exactly one base word, whose own forms table lists the word, the rule points the edge at that word instead, so `mele`'s senses 1 to 3 read `mela`. That redirect rests on this record's two conditions, taken from the record's form sense: its gloss names the base word after "di", and the base word's table lists the record's word. Where the form senses name several base words, or the one they name is not confirmed, the edge is removed; the page never guesses an edge. Rule `it-form-of-meaning-edge/v1` does it.
  - **How it is stored.** A removal is a new kind of edge correction that keeps the source's edge verbatim beside the record (`EdgeRemoval`, `RemovedEdge.removes` in `src/italian/curatedCorrections.ts`) and cites the record's it.wiktionary page, which shows the meaning gloss, by revision id. It is written as a `corrected_edge` row that names no word, and a lookup reads the sense as having no edge. A redirect is an edge correction like v2's, citing the record's page, which shows the form sense's gloss, and the base word's page. `source_record_json` and the record's `form_of_edge` rows stay as imported.
  - **The count.** On `it-0c432803` the rule removes 342 edges and points 258 at the record's own base word: 600 senses of 468 records ([report](../reports/2026-10-09-form-of-meaning-edges.md)).
